# 论文修改意见收集（FEEDBACK）

> **用途**：集中记录你本人与导师的论文修改意见，agent 按此文件逐条处理。
> **使用方式**：把意见按下面格式追加到本文件（或直接告诉我/编辑章节文件），处理完一条勾一条。

## 填写格式（每条意见一行块）

```
- [ ] [来源: 本人/导师] [日期] [目标: 章节/小节/图号]
  意见内容：……
  （可选）处理说明：……（agent 完成后补充）
```
